## Employee REST API Automation with Newman Report

## About this project

This project is focused on functional testing and automation of an Employee REST API using Postman. It covers 30+ positive and negative test cases for login, employee creation, retrieval, update, deletion, and query-based searches.

The project uses dynamic/random test data, JavaScript assertions, Postman environments, and Newman for automated collection execution and HTML test report generation.

## Tools & Technologies
-Postman
-Visual Studio Code
